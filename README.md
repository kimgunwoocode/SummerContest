🎮드래곤전
<br></br><br></br>
<게임소개>
드래곤전은 한국의 전통 설화를 기반으로 한 독특한 세계관 속에서 펼쳐지는 2D 메트로베니아 장르의 액션 어드벤처 게임입니다. 고전 설화의 요소를 현대적으로 재해석하고, 드래곤과의 만남으로 이야기를 풀어내며 깊이 있는 몰입감을 제공합니다.
플레이어는 알에서 갓 깨어난 귀여운 드래곤이 되어, 자유로운 탐험을 통해 자신에게 얽힌 비밀과 세상의 진실을 파헤칩니다. 이 과정에서 점차 더 넓은 세계를 탐험하고 퍼즐을 해결해 나가며, 다양한 능력을 습득하여 더 많은 것들을 깨우치게 될 것입니다.
